What we do

Three things, done properly

The suite does not try to be an accounting package. It does the one job that eats your team's evenings — matching two records and explaining what does not agree.

Match, field by field

GSTIN, invoice number, date, taxable value and each tax head are compared column by column. A match means the same invoice — not a similar one.

A reason on every row

Matched, value differs, missing in 2B, duplicate — each line carries a reason you can filter on, so the exceptions are the only thing left on screen.

An Excel you can file

One workbook, two sheets: a summary of what reconciled, and an exceptions sheet with the reason on each row. No re-typing into a working paper.

Why practices use it

Built around how a practice actually reconciles

Most reconciliation tools assume a single company. A practice has forty clients, each with two files and a deadline. The suite is set up for that: one file at a time, one client at a time, nothing left on someone else's server.

  • One invoice pairs once. No invoice matched twice, no double counting in the summary.
  • ₹1 configurable tolerance. Round-off differences settle themselves, and you set the tolerance your practice works to.
  • A filterable reason on every row, so review is reading down a column, not opening each invoice.
  • Excel report with summary and exceptions — the two sheets your article actually asks for.
  • 5 UI languages, so the person doing the reco can work in the one they read fastest.
  • Files stay in the browser. The sheets are read on your machine; nothing is uploaded to us.
