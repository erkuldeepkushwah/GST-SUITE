Five modules, one reporting period

Each module takes the portal file and the books file, reconciles line by line, and hands back an Excel report with the exceptions listed rather than buried.

GST 2A / 2B

ITC reconciliation

Portal 2A/2B Excel against the books purchase register.

  • B2B and CN/DN matching
  • GSTR-9 ITC summary
  • Filter by invoice date, return period, or both
GSTR-1 & 3B

Return tie-out

Portal GSTR-1 JSON, books GSTR-1 Excel and the 3B values or 3B PDF.

  • 3B PDF read automatically, still editable
  • Invoice-level B2B and CDNR reconciliation
  • HSN summary check
  • 3B tie-out against filed figures
Bank

Bank reconciliation

Bank statement (.xls/.xlsx) against the Tally bank ledger.

  • Matched, timing and bank-only entries
  • Opening balances rolled to the From date
  • Closing reconciliation with unexplained difference
TDS

TDS reconciliation

Tally TDS ledger against the CA's TDS return.

  • Monthly tie-out for any date range
  • Entry classification and exceptions
Stock

Stock tie-out

Tally stock report (snapshot) or the movement register.

  • Totals tie-out with NOT TIED flagged
  • Movement: opening + inward − outward vs closing, per item
  • Optional cross-check against the closing summary
Reports

Excel output

Every module writes a workbook you can attach to the file.

  • Dashboard KPIs per module
  • Exceptions listed, not summarised away
  • Firm branding on the header

Built for how a practice actually works

Periods, languages and honest statuses — the small things that decide whether a reconciliation tool gets used in March or gets abandoned in July.

One period, or per-module overrides

Monthly, quarterly, financial year or a custom range. Each module can inherit the common period or set its own.

Late-reported invoices stay visible

GST 2A/2B can filter on invoice date, return period or both, so invoices reported late in a later month still appear for comparison.

Statuses that do not flatter

A total that does not tie is shown as NOT TIED. Missing optional columns do not stop a run, and the dashboard reports what the period filter left out.

Five languages in the sidebar

English, Hindi, Mandarin Chinese, Spanish and French. Screen text translates; the Excel contents stay exactly as written.

Desktop and cloud, same code

One shared Streamlit app. A Windows launcher wraps it in a native window; Streamlit Cloud serves the same entry file.

Client data stays out of git

The repository blocks spreadsheets, JSON, CSV and database files by default, and keeps only the safe example files.

Run it yourself

The repository is public. Clone it, install the pinned versions and start the app — or build the Windows bundle if you prefer a desktop icon.

Local (any OS)

pip install -r requirements.txt
streamlit run gst_suite_app.py

Open the URL the terminal prints, enter the 15-character GSTIN in the sidebar, pick the period, and upload the files for the module.

Windows desktop build

build_windows.bat

Produces dist\GSTReco\GSTReco.exe. Application data is kept in Documents\GST Reco.
